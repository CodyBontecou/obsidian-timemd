# Web history review

Use this with exports that include **Browsing History** and/or **Top Domains**.

## Recent timeline

```timemd
view: web-history
title: Recent browsing
tab: timeline
limit: 25
```

## Top domains

```timemd
view: web-history
title: Top domains
tab: domains
limit: 12
```

## Hourly browsing activity

```timemd
view: web-history
title: Browsing by hour
tab: activity
```

## Browser-specific slice

```timemd
view: web-history
title: Safari browsing
browser: Safari
tab: timeline
limit: 15
```

## Review prompts

- Which domains were research, and which were drift?
- Which browser has the highest concentration of productive work?
- What domains should be added to allow/block lists?
- Which browsing windows should become saved reading lists instead of live tabs?
